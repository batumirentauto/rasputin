# Сайт Павла Распутина — Бизнес-медиация и разрешение партнёрских кризисов

Премиальный лендинг и веб-сервис для независимого бизнес-медиатора Павла Распутина.

Дизайн и визуальная система полностью воспроизводят эстетику и архитектуру референса:
- **Цветовая палитра:** Глубокий винный (`#73162b`), тёплая бумага (`#f5f5f2`), розовая пудра (`#c88494`), графит (`#202020`).
- **Типографика:** Заголовки `Prata` (классический благородный антиквенный шрифт с кириллицей) + основной текст `Manrope` (современный гротеск).
- **Интерактивные модули:**
  - Симулятор переговорных кейсов в интерфейсе смартфона (Дедлок 50/50, Раздел бизнеса / Buyout, Кризис доверия);
  - Интерактивный аккордеон частых вопросов (FAQ);
  - Конфиденциальная форма заявки на экспресс-аудит с обработкой `/api/lead` и сохранением лидов;
  - Плавные reveal-анимации появления блоков при скролле (IntersectionObserver).

## Структура сайта
1. **Главный экран (Hero)** — оффер, 4 ключевых преимущества, портрет Павла Распутина и быстрые действия.
2. **О медиации (Clarity)** — суть бизнес-медиации, для кого, задачи, формат работы.
3. **Ситуации (Use Cases)** — дедлок 50/50, цивилизованный развод партнёров, подозрения и нарушение договорённостей.
4. **Процесс (Format)** — интерактивный телефон с 3 реальными сценариями переговоров.
5. **Масштаб практики (Ecosystem)** — кризисное урегулирование vs партнёрские соглашения «на берегу».
6. **Медиация vs Суд (Difference)** — сравнение судебной войны с арбитражем и экологичной медиации.
7. **Методология (Framework)** — 4 этапа и архитектурная карта переговоров в закрытом периметре.
8. **Принципы (Trust)** — равноудалённость, тайна, добровольность, экономический прагматизм с полноростовым портретом.
9. **Результаты (Outcomes)** — сохранение стоимости бизнеса, экономия 1,5–3 лет жизни, сотни миллионов рублей.
10. **Экспресс-аудит (Pilot)** — пошаговый план первого входа в переговоры.
11. **Принцип медиатора (Portrait Band)** — манифест Павла Распутина с портретом в кресле.
12. **База знаний (Knowledge)** — практические разборы и статьи по корпоративным конфликтам.
13. **Вопросы и ответы (FAQ)** — раскрывающиеся ответы по юридической силе (ФЗ № 193), отказу партнёра от контакта и др.
14. **Конфиденциальная форма (CTA)** — форма заявки на экспресс-аудит под защитой NDA.
15. **Подвал (Footer)** — ссылки, юридический статус и контакты.

## Запуск проекта

### Вариант 1: Через Node.js (с работающим API формы)
```bash
npm start
# Сервер запустится на http://localhost:3001 (или указанном через PORT)
```

### Вариант 2: Статический запуск
Файл `index.html` полностью автономен и может открываться напрямую в браузере или через любой HTTP-сервер:
```bash
python3 -m http.server 8080
```

### Развёртывание (Railway / Vercel / Render / VPS)
Проект готов к мгновенному деплою:
- В репозитории есть `server.js` и `package.json` со скриптом `npm start`;
- Заявки с формы сохраняются в `leads.jsonl`.
